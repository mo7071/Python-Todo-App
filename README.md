Task 2 (Easy) – To-Do List Application
Description

Create a Python application to manage daily tasks efficiently. Users can add, view, update, delete, and mark tasks as completed. Task data is stored in a JSON file.

Features
Add Tasks
View All Tasks
Update Tasks
Delete Tasks
Mark Tasks as Completed
Save Tasks to JSON File
Load Saved Tasks Automatically
Technologies Used
Python
JSON Module
Task Workflow
Add tasks to the list.
Display all tasks.
Mark tasks as completed.
Delete unwanted tasks.
Save task data to a file.
How to Run
Install Python 3.
Download or clone this repository.
Open the project folder.
Run the following command:
bash
python todo.py
