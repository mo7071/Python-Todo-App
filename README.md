# Python Todo App

A simple command-line Todo Application built with Python using Object-Oriented Programming (OOP) concepts.

This project allows users to manage their daily tasks directly from the terminal.

## Features

* Add a new task
* View all tasks
* Update an existing task
* Delete a task
* Mark a task as completed
* Exit the application
* Prevent duplicate tasks
* Handle invalid task numbers

## Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* Lists
* Functions and Methods
* Loops
* Conditional Statements
* `enumerate()`
* `match-case`
* User Input

